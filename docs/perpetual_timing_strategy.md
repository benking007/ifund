# 永续组合 + Resonance 择时联合策略

## 策略逻辑

将 iFund 的永续组合选基能力与 Resonance 的择时能力结合，形成"择时定买卖、选基定持仓"的完整交易策略。

### 核心原则

1. **择时层（Resonance）**：基于沪深300ETF(510300)多指标共振系统，产出买点/卖点信号
2. **选基层（iFund 永续组合）**：在每个买点，以该日为决策日(as_of)，运行永续组合引擎筛选 10 只基金
3. **无前视偏差**：选基算法（质量评分、相关性、greedy 选择、风险平价配权）只使用决策日之前的数据
4. **满仓轮动**：买点 100% 仓位买入 → 卖点全部卖出 → 空仓等待下一个买点

### 执行流程

```
Resonance 买点信号
       │
       ▼
以买日为 as_of 运行永续组合引擎
  ├─ 硬门槛：任期≥3年、规模2~400亿、净值≥750天
  ├─ 质量评分：滚动夏普/索提诺/风格漂移（只用 as_of 前数据）
  ├─ 份额去重：同基金保留最优份额
  ├─ 对齐窗口：[ALIGN_START, as_of] 计算残差相关性
  ├─ Greedy 选择：质量 - λ×残差相关 + μ×风格覆盖
  └─ 风险平价配权：ERC 迭代 + WMAX=20% 上限
       │
       ▼
产出 10 只基金 + 权重
       │
       ▼
100万满仓买入，持有到卖点
       │
       ▼
Resonance 卖点信号 → 全部卖出
       │
       ▼
计算本轮收益，等待下一个买点
       │
       ▼
复合所有轮次 → 总收益
```

### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| ALIGN_START | 2023-07-01 | 相关性对齐窗口起点 |
| MIN_COMMON_DAYS | 250 | 对齐后最少共同交易日 |
| TARGET_HOLDINGS | 10 | 目标持仓数 |
| WMAX | 20% | 单只最大权重 |
| LAMBDA_DIV | 0.6 | 分散度惩罚系数 |
| MU_STYLE | 0.5 | 风格覆盖奖励系数 |
| MAX_PER_COMPANY | 2 | 同公司最多入选 |
| 择时标的 | 510300 | 沪深300ETF |

### 收益计算

- **组合收益**：按风险平价权重加权各基金的持有期收益（买日NAV → 卖日NAV）
- **基准收益**：510300 同期涨跌幅
- **复合收益**：各轮 (1+r) 连乘 - 1
- **超额**：复合组合收益 - 复合基准收益

## 运行方式

```bash
cd ifund/backend

# CLI 运行（需 Resonance 后端在 :8001 运行，否则用内置 FALLBACK_PAIRS）
./venv/bin/python3 ifund_cli.py historical perpetual --preset 1
./venv/bin/python3 ifund_cli.py historical perpetual --preset 1 --json
```

## 数据来源

- **买卖信号**：Resonance API `GET :8001/api/resonance/trades?code=510300`，离线回退到 `FALLBACK_PAIRS`
- **基金净值**：iFund `data.db` 的 `fund_nav` 表
- **基准价格**：腾讯行情 API（510300 日线）
- **候选池**：预设镜像快照（`fund_snapshots` 表）
